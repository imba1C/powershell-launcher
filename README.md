## English

An all-in-one interactive CLI launcher designed to effortlessly run PowerShell scripts (`.ps1`) on Windows operating systems.

### ⚠️ Encoding Requirements

* **EN:** All `.ps1` scripts containing non-ASCII characters (e.g., Cyrillic) **MUST** be saved in **UTF-8 with BOM** encoding. To ensure correct console output, add the following line at the very beginning of your PowerShell script:
  ```powershell
  [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
  ```
* **Batch (`.bat`):** Must be saved **WITHOUT BOM** (Standard UTF-8 or ANSI/Windows-1251), otherwise Windows `cmd.exe` will fail to execute the first line.

---

### ❓ What problem does it solve?
1. **Bypasses Restrictions:** By default, Windows blocks the execution of external PowerShell scripts due to security policies. This batch script automatically bypasses this restriction safely (`-ExecutionPolicy Bypass`) without changing your global system settings.
2. **Interactive Menu:** If there are multiple scripts in the folder, the launcher automatically scans the directory and generates a clean, numbered menu for selection.
3. **Instant Launch:** If there is only one script in the folder, it will run instantly after pressing Enter.
4. **Special Character Handling:** Correctly processes special characters (`&`, `|`, `<`, `>`, etc.) in filenames and fully supports UTF-8 encoding.

### 📁 Directory Structure
For the launcher to work, simply place the `run.bat` file into the folder where your `.ps1` scripts are stored:

```text
My-Scripts/
├── run.bat       <- This launcher
├── backup-db.ps1      <- Your useful scripts
├── clear-cache.ps1
└── ...
```

### 🚀 How to Use
1. Copy `run.bat` into your scripts folder.
2. Double-click `run.bat` to run it.
3. Type the number of the desired script and press **Enter**.
4. Once the script finishes, the console window will stay open so you can review the output or error logs.

### 🛠️ System Requirements
* **OS:** Windows 7 / 10 / 11 / Windows Server
* **Environment:** PowerShell pre-installed (comes default with modern Windows versions).

## Русский

Универсальный интерактивный CLI-загрузчик для удобного запуска PowerShell-скриптов (`.ps1`) в операционной системе Windows.

### ⚠️ Важное примечание по кодировке

* **RU:** Все скрипты `.ps1`, содержащие кириллицу, **ОБЯЗАТЕЛЬНО** должны быть сохранены в кодировке **UTF-8 с BOM**. Чтобы русский текст корректно отображался в консоли, добавляйте в самое начало каждого PowerShell-скрипта следующую строку:
  ```powershell
  [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
  ```
* **Batch (`.bat`):** Файл лаунчера (`run.bat`) должен быть сохранен строго **БЕЗ BOM** (в обычном UTF-8 или ANSI/Windows-1251). Если оставить BOM, Windows выдаст ошибку на первой же строке.

---

### ❓ Какую проблему это решает?
1. **Обход ограничений:** Windows по умолчанию блокирует запуск внешних PowerShell-скриптов из-за политики безопасности (`ExecutionPolicy`). Этот батник автоматически обходит ограничение безопасным способом (`-ExecutionPolicy Bypass`), не меняя глобальные настройки системы.
2. **Интерактивное меню:** Если в папке находится несколько скриптов, лаунчер автоматически сканирует директорию и выводит удобное нумерованное меню для выбора. 
3. **Быстрый запуск:** Если скрипт всего один, он запустится сразу (после подтверждения по нажатию Enter).
4. **Безопасность символов:** Корректно обрабатывает спецсимволы (`&`, `|`, `<`, `>`, etc.) в именах файлов и поддерживает кодировку UTF-8.

### 📁 Как настроить структуру папки
Чтобы лаунчер работал, просто положите файл `run.bat` в папку, где хранятся ваши `.ps1` скрипты:

```text
Мои-Скрипты/
├── run.bat       <- Этот лаунчер
├── backup-db.ps1      <- Ваши полезные скрипты
├── clear-cache.ps1
└── ...
```

### 🚀 Инструкция по использованию
1. Скопируйте `run.bat` в папку с вашими скриптами.
2. Запустите `run.bat` двойным кликом.
3. Введите номер нужного скрипта из списка и нажмите **Enter**.
4. После завершения работы скрипта консоль не закроется сама — вы сможете увидеть результат выполнения или логи ошибок.

### 🛠️ Системные требования
* **ОС:** Windows 7 / 10 / 11 / Windows Server
* **Окружение:** Наличие установленного PowerShell (предустановлен во всех современных версиях Windows).
